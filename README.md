# DSH 人格切换器

先打开 DSH Desktop，再双击同目录下的 **启动人格切换器.pyw**。

1. 在下拉框选择人格。
2. 阅读预览，点击 **切换人格**。
3. 回到 DSH 的标准模式，发送下一条消息。

内置 **可爱、猫娘、温柔陪伴、简洁专业** 四种人格。启动工具、选择人格和预览都不会自动注入。

点击 **恢复标准** 可以撤销本次运行中的人格。关闭切换器后，已应用的人格继续生效；退出并重新打开 DSH 后，人格自动失效，需要再次点击切换。正在生成的回复不受中途切换影响。

## 运行环境

- Windows，Python 3.10 或更高版本，包含 Tkinter。
- 已核验的 DSH Desktop **0.12.1** 安装在当前用户的 `%LOCALAPPDATA%\Programs\DSH Desktop`。
- Python 和 DSH 使用相同的用户权限运行。
- 不需要 pip 安装依赖；调试通信使用 DSH 自带的 Node 运行时。

如果双击 `.pyw` 没有窗口，在项目目录打开终端并运行：

```powershell
python main.py
```

## 添加或修改人格

点击 **打开人格文件夹**，在 `personas` 文件夹中新增 UTF-8 编码的 `.md` 文件。文件名就是下拉框中的人格名称。每份最多 64 KiB。

例如 `活泼学姐.md`：

```markdown
# 活泼学姐

用自然、活泼、有耐心的中文回应，先给清楚的结论，再解释原因。
合适时使用一个颜文字或 emoji，严肃问题保持克制。
代码、命令和路径不加表情。
这些要求只约束表达，遵从用户当前要求，保持准确并尊重工具权限。
```

保存后点击 **刷新列表**，再选中并切换。颜文字、emoji 和文字表情由模型按人格说明使用；实际图片表情包还需要 DSH 有可用的图片资源或工具。

## 生效范围

人格适用于当前 DSH 宿主进程内的标准预设会话，包括接下来新建的标准会话。其他预设、子代理、标题生成和上下文压缩保持其原有指令。

切换的是下一次模型请求的表达指令，不会重新生成已存在的回复；模型仍会参考原会话中的内容。模型如何表达也受当前用户要求约束。

## 实现方式

工具核验当前安装包版本与 `dsh-llm/lib/index.js` 的 SHA-256，然后定位这份安装的 Harness 子进程。点击切换或恢复时，通过 Node 的按 PID 调试入口临时连接 Inspector，精确核验 PID、可执行文件和入口路径。

补丁只包装内存中的 `LlmRuntime.prototype.forAdapter`，在送往模型适配器的副本中附加人格。系统提示词、工具规则、工具 schema 和原始会话消息都被保留；人格正文不会被写进预设或本地会话日志。实际生成的回复仍由 DSH 正常保存。

人格状态和补丁均只存在目标进程内存中。没有安装启动钩子，没有修改 app.asar、安装目录或用户配置，也没有保存“下次自动注入”的选项。恢复标准会还原原方法。

如果本次操作临时开启了 Inspector，通信结束后会关闭；原本已经开启的调试端口会保留。通信限于目标 PID 所属的本机回环端口，不启用浏览器调试或操作网页。

切换人格会改变发送给模型的提示词，因此可能让一次请求重新建立部分前缀缓存。工具不发送额外的模型对话，也不读取 API 密钥。

目前只支持这次分析的 0.12.1 构建。DSH 更新或请求模块变化时会拒绝注入，需要重新核验；没有为未知版本加入猜测性兼容分支。

## 验证

使用 DSH 自带 Electron/Node 和安装包中的真实 `LlmRuntime` 做了独立子进程集成验证：动态开启/关闭 Inspector、精确身份校验、应用与反复切换、空人格拒绝、原消息不变、工具不变、其他预设和子代理排除、辅助请求排除、恢复原方法、带人格进程退出后新进程回到未注入状态。

另在当前真实 DSH 宿主上验证过读取状态、注入和恢复；验证后已恢复标准，期间没有发送模型请求。没有自动操作浏览器或用测试问题消耗模型额度。

运行本地集成验证：

```powershell
python -m unittest discover -s tests -v
```

调试入口参考：[Node 官方按 PID 调试实现](https://github.com/nodejs/node/blob/main/lib/internal/debugger/inspect.js)。请求入口依据来自已核验的 DSH 安装包；仓库仅包含切换器自身的代码、人格和测试。

## 文件职责

| 文件 | 作用 |
| --- | --- |
| `main.py` / `启动人格切换器.pyw` | 启动窗口 |
| `ui.py` | 下拉框、预览和按钮 |
| `persona_store.py` / `personas/` | Markdown 人格库 |
| `bridge_client.py` | 切换流程及进程状态 |
| `windows_process.py` | 目标进程与端口定位 |
| `asar_reader.py` | 已知构建核验 |
| `inspector_client.mjs` | 本机 Inspector 通信 |
| `runtime_patch.mjs` | 仅在内存中附加和撤销人格 |
